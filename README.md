# Dan Boneh《Cryptography I》中文学习笔记

本仓库收录我在学习 Dan Boneh《Cryptography I》课程过程中整理的中文笔记，内容围绕现代密码学的基本概念、安全定义、典型构造和常见攻击展开。

> 本仓库为个人学习记录，并非 Stanford University、Dan Boneh 教授或课程团队发布的官方资料。笔记可能存在理解偏差或疏漏，请以课程原始材料和权威文献为准。

## 内容概览

当前仓库包含 **14 份 PDF，共 212 页**：

- **11 份课程笔记**：覆盖第 2 课至第 12 课；
- **3 份专题笔记**：CBC、PRG/PRF/PRP、密码学哈希函数；
- 当前暂未收录第 1 课笔记。

课程内容大致形成如下学习路径：

```text
对称加密 -> 流密码与伪随机性 -> 分组密码及其工作模式
       -> 消息完整性与抗碰撞 -> 认证加密 -> 特殊加密场景
       -> 密钥交换 -> 数论基础 -> 公钥加密
```

## 推荐阅读顺序

1. 第 2-4 课：伪随机性、流密码、分组密码与工作模式；
2. 第 5-7 课：完整性、哈希函数与认证加密；
3. 第 8 课：数据库、磁盘等特殊场景中的密码学需求；
4. 第 9-10 课：密钥交换及其所需的数论工具；
5. 第 11-12 课：RSA 与 Diffie-Hellman/ElGamal 两条公钥加密路线。

## 核心知识脉络

- **保密性**：一次一密、伪随机生成器、流密码、PRF、PRP、分组密码、语义安全和 CPA 安全。
- **完整性**：MAC、抗碰撞哈希、消息认证和不可伪造性。
- **认证加密**：主动攻击、CCA 安全、AEAD、TLS/WEP 案例及填充预言机攻击。
- **密钥建立**：Merkle Puzzles、Diffie-Hellman、中间人攻击和公钥加密。
- **公钥密码**：数论基础、陷门置换、RSA、OAEP、ElGamal 及 CDH/Hash-DH 假设。
